# 🌤️ SkyCast – Weather Forecast App

SkyCast is a modern and responsive weather forecast web application built using React. It provides real-time weather information and a 5-day forecast for cities around the world using the Open-Meteo API.

## 🚀 Live Demo

https://skycast-akanksha.bolt.host

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ View current temperature
- ☁️ Display weather conditions with icons
- 💧 Check humidity
- 💨 View wind speed
- 📅 5-day weather forecast
- 🌙 Dark and Light mode
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- ❌ Friendly error message for invalid city searches

## 🛠️ Tech Stack

AI Tools: Bolt.new, ChatGPT

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/grandeakanksha-hub/skycast-weather-app.git
```

2. Navigate to the project folder

```bash
cd skycast-weather-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

## 🌍 API Used

This project uses the **Open-Meteo API**, which provides free weather data and does not require an API key.

Website:
https://open-meteo.com/
